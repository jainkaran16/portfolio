# Karan Jain — Portfolio

The source for Karan Jain's personal portfolio, showcasing work in agentic AI, explainable AI, accessibility, computer vision, and AI security.

Visit the live site: [karan-jain-projects.litheseed1.chatgpt.site](https://karan-jain-projects.litheseed1.chatgpt.site)

## Structure

- `dist/` contains the static website.
- `.openai/hosting.json` contains the hosting configuration.

Open `dist/index.html` in a browser to view the site locally.
